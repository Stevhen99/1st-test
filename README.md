# NutriTrack - Daily Calorie & Macro Tracker

A lightweight, responsive calorie and macronutrient tracker built with vanilla **HTML**, **CSS**, and **JavaScript**. No frameworks, no external libraries, no build steps, and no backend—all data is stored locally in your browser.

## Features

- **Daily Calorie Tracking**: Circular SVG gauge displaying calories consumed, daily calorie goal, and remaining or surplus calories.
- **Macronutrient Breakdown**: Visual progress bars for Protein, Carbohydrates, and Healthy Fats.
- **Hydration Tracker**: Log daily water intake with quick-add buttons (+250ml, +500ml, -250ml) and progress percentage.
- **Meal Categories**: Organize food logs into Breakfast, Lunch, Dinner, and Snacks with subtotals.
- **Food Presets & Quick Add**: Built-in searchable library of common foods with pre-configured macros, plus custom food entries.
- **7-Day Trend Chart**: Pure HTML5 Canvas 2D bar chart visualizing daily calorie intake against your target.
- **Goal Customization**: Set personalized targets for calories, macros, and water.
- **Browser Persistence**: All data is saved automatically in `localStorage`.
- **Data Portability**: Export your data to JSON for backup, import existing backups, or reset data.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Start logging your meals!
